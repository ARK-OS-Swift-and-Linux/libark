# Credits & Acknowledgements

`libark` stands on the shoulders of giants. We would like to express our gratitude to the following projects and communities:

- **The Swift Project**: For providing the memory-safe, highly performant language that makes this abstraction layer possible.
- **swift-system**: For providing idiomatic, low-level Swift bindings to system interfaces.
- **swift-argument-parser**: For powering our expressive, type-safe CLI interfaces on top of `libark`.
- **The Linux Kernel**: For the POSIX primitives and system interfaces that power modern computing.
- **GNU C Library (glibc)**: For the standard C library implementation utilized in our lower-level bindings.

We also thank all of the contributors and maintainers across the open-source ecosystem who continually push systems programming forward.
