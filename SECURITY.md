# Security Policy

Security is the primary directive of `libark`. As a foundational layer communicating directly with the Linux kernel via system calls, any vulnerability here cascades upward to all relying applications.

## Supported Versions

Currently, only the main development branch is supported with security updates. 

## Reporting a Vulnerability

If you discover a potential security vulnerability in `libark`, please **do not** open a public issue.

Instead, please send an email to our security team at `arkosgogs@gmail.com` with:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the system.

We treat all security reports with the highest priority and will coordinate with you to publish a fix securely.
